關於 WKI Lab

WKI Lab 是 WK Infovision 的技術實驗空間，用於測試、開發與管理我們的內部工具、資料庫與 Web 技術原型。 這裡不是品牌展示頁，也不是官方網站，而是支撐整個 WKI 生態系統的技術後台。

Lab 的角色

WKI Lab 的主要用途包括：

  • 技術測試（HTML / CSS / JavaScript）
  • WebApp 原型與互動功能
  • JSON 資料庫（角色、世界觀、商品資料）
  • Super.site 外部素材（CDN）
  • EPUB / 工具相關技術檔案
  • 內部工具與開發備份

為什麼需要 Lab？

WK Infovision 的主站專注於品牌、內容與出版，而 Lab 則負責技術層面的實驗與支援。 兩者分工明確，確保主站保持乾淨一致，而技術開發可以自由演進。

  • 主站（Super.site）＝品牌前台
  • Lab（GitHub Pages）＝技術後台

這種分離式架構讓我們能夠快速測試新功能，同時保持主站的穩定與一致性。

Lab 的結構

  • /assets — Super.site 引用的素材
  • /data — JSON 資料庫
  • /tools — 技術工具與原型
  • /tests — HTML / JS 測試頁

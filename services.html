WKI Lab｜技術能力

WKI Lab 是 WK Infovision 的技術實驗空間，用於開發、測試與管理內部工具、資料庫與 Web 技術原型。 本頁展示 Lab 目前涵蓋的技術範圍與能力。

1. Web 技術測試（Web Experiments）

  • HTML / CSS / JavaScript 測試
  • 互動功能 Prototype
  • 前端元件與 UI 行為測試
  • 跨平台相容性測試

2. WebApp 原型（WebApp Prototypes）

  • 工具介面 Prototype
  • 互動式資料頁
  • 角色查詢器 / 世界觀工具
  • 小型應用程式 Demo

3. JSON 資料庫（Data Layer）

  • 角色資料庫（Characters JSON）
  • 世界觀資料（Lore / Timeline JSON）
  • 商品資料（Mochidog / Moe Seal）
  • 內容結構資料（Chapters / Metadata）

4. 靜態素材管理（Assets Management）

  • 圖片素材（PNG / WebP）
  • SVG / Icon
  • 背景素材
  • 技術測試所需的靜態檔案

5. EPUB / 電子書技術（EPUB & eBook Tech）

  • EPUB CSS 測試
  • 直排排版研究
  • 圖片推頁測試
  • 電子書技術備份

6. 內部工具（Internal Tools）

  • 資料轉換工具
  • 內容生成工具
  • 自動化腳本（前端）
  • 技術流程測試

Technical Development Space

WKI Lab 是 WK Infovision 的技術實驗空間，用於測試、開發與管理內部工具、資料庫與 Web 技術原型。 本平台專注於技術研究與開發，不作商業展示用途。

Lab 的用途

  • Web 技術測試（HTML / CSS / JavaScript）
  • WebApp 原型與互動功能開發
  • JSON 資料庫管理（角色、世界觀、商品資料）
  • 靜態素材管理（圖片、SVG、技術測試素材）
  • EPUB / 電子書技術研究
  • 內部工具與流程測試

Lab 結構

  • /assets — 靜態素材
  • /data — JSON 資料庫
  • /tools — 技術工具與原型
  • /tests — HTML / JS 測試頁

說明

WKI Lab 為技術開發用途而設，內容可能包含測試頁面、原型功能與未完成的技術實驗。 本平台不提供對外服務或聯絡功能。
